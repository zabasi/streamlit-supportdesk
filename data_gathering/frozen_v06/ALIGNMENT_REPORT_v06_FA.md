# گزارش مختصر اصلاح داده و ارزیابی

Streamlit Session State | v06 | ۲۰۲۶/۱۰/۰۹

نسخه v06 آماده شد. ارجاع شواهد، تاریخ کیس‌ها، اطلاعات موردنیاز و مراحل گفتگو با corpus هماهنگ شدند. متن و کد ۵۴۰ رکورد منبع بدون تغییر حفظ شده‌اند.

| موضوع | اصلاح انجام‌شده |
| --- | --- |
| ارجاع شواهد | ۶۰ شاهد قبلی به بازه دقیق متن corpus نگاشت شدند؛ ۴ شاهد رسمی از منابع موجود اضافه شد. شناسه منبع یکتا است و URL از متادیتای همان منبع خوانده می‌شود. |
| بازه‌ها و چانک‌ها | هر شاهد متن دقیق، ابتدا و انتهای بازه و هش دارد. پایان بازه انحصاری است؛ ابزار نگاشت به چانک‌های واقعی آینده نیز اضافه شد. |
| تاریخ و محیط | تاریخ ایجاد و به‌روزرسانی ۳۰ کیس اضافه شد. ۲۱ اصلاح در فیلدهای محیط انجام شد؛ موارد صریح از گزارش استخراج و مقادیر نامعتبر کنار گذاشته شدند. |
| اطلاعات بیشتر | ۳۰ نیاز اطلاعاتی در کیس‌های نیازمند توضیح یا ارجاع ثبت شد: سؤال، دلیل و اثر پاسخ بر تصمیم. اطلاعاتی که قبلاً داده شده دوباره درخواست نمی‌شود. |
| گفتگوی چندمرحله‌ای | ۱۰ سناریو مرحله‌بندی شد؛ پیام بعدی پس از پاسخ عامل آزاد می‌شود. ۶ نمونه دارای سابقه گفتگو اضافه شد و مستقل از کیس پایه شمرده نمی‌شود. |
| منابع غیرمستندات | ۸ آزمون مکمل برای issue، کامنت، یادداشت انتشار و منبع لینک‌شده اضافه شد؛ اعتبار پیشنهاد، نقش شاهد و محدوده نسخه ارزیابی می‌شود. |
| ارتباط و تکرار | ۲۰۲ ارجاع صریح ثبت شد؛ ۱۵ issue دارای شماره issue مرتبط است. شناسه‌های تکراری متادیتا حذف و نسخه اصلی در سابقه ممیزی حفظ شد. |
| دو مجموعه ۱۵تایی | ۱۵ کیس ارزیابی و ۱۵ کیس تست اصلی و توازن دسته‌ها حفظ شد. نمونه‌های دارای سابقه و آزمون‌های مکمل در فایل‌های جدا قرار دارند. |

اعتبارسنجی ساختار، تطابق متن شواهد، شناسه‌ها و هش‌ها موفق بود. ۱۷ بررسی آفلاین قرارداد داده و تحویل مرحله‌ای گفتگو نیز گذشت.

این نتایج، کیفیت پاسخ عامل یا حل قطعی باگ‌های تاریخی را ثابت نمی‌کند. اجرای واقعی عامل، اتصال به tracker، چانک‌سازی، embedding و تأیید انسانی هنوز انجام نشده‌اند. بررسی پوشش، پشتیبانی از پاسخ محدود، سؤال تکمیلی یا ارجاع را سنجیده است.

بسته کامل شامل corpus، دو مجموعه اصلی، rubricها، سناریوها، ابزارها و ممیزی است. بسته ورودی چانک‌سازی فقط corpus و قرارداد مصرف آن را ارائه می‌کند.
