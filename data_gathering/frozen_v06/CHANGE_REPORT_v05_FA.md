# گزارش بررسی لینک های دیتاست نسخه ۵

نسخهٔ v05 بررسی ارجاع‌های داخل متن نسخهٔ v04 را اضافه می‌کند. هدف، فراهم‌کردن اطلاعات فنی تکمیلی و ثبت ارتباط منابع پیش از چانکینگ است. متن و کد هر ۴۷۲ رکورد قبلی بدون تغییر حفظ شده‌اند؛ ۶۸ رکورد فنی منتخب اضافه شده و مجموع ورودی به ۵۴۰ رکورد رسیده است.

| شاخص | نتیجه |
| --- | ---: |
| آدرس مرجع متمایز در متن منتخب | ۳۴۱ |
| وقوع ارجاع در متن | ۴۰۰ |
| صفحهٔ مقصد متمایز | ۳۲۱ |
| مستند تکمیلی جدید | ۳۳ |
| بحث فنی، شرح تغییر یا کد دارای مرجع ثابت جدید | ۳۵ |
| رابطهٔ ثبت‌شده میان رکوردهای موجود و مقصد منتخب | ۱۵۸ |

۶۲ آدرس به محتوای منتخب تازه و ۵۵ آدرس به رکورد یا بازتولید موجود متصل شدند. ۱۴۱ ارجاع GitHub در ریلیز نوت‌ها به عنوان منشأ تغییر حفظ شدند؛ چون شرح تغییر نسخه در دیتاست موجود است، بدنهٔ مقصد صرفاً برای تکرار همان ارجاع دریافت نشد. دسته‌های دیگر مانند دمو، کد شاخهٔ متغیر، مرجع عمومی، صفحهٔ خصوصی یا مقصد غیرقابل دریافت در فهرست تصمیم‌ها مشخص‌اند. این شمارش به معنی بازشدن و تأیید فنی تمام مقصدها نیست.

## نمونه مربوط به کامنت ۹۹۸۹۰۹۵۱۹

لینک «here» به مستند رسمی Session State هدایت می‌شود. رکورد این مستند از قبل موجود بود و اکنون ارتباط کامنت با آن در metadata.linked_source_ids ثبت شده است. متن مستند دوباره وارد نشده و آدرس اصلی داخل متن کامنت حفظ شده است.

## محتوای افزوده و کنترل کیفیت

بخش‌های منتخب شامل قواعد وضعیت ویجت، کال‌بک، فرم، اجرای جزئی، پیمایش صفحه، تست، سریال‌سازی، گزارش شکست راهکارها و کد دارای commit ثابت هستند. سلام، تشکر و خطاب‌های شخصی در متن تازهٔ منتخب وارد نشده‌اند. نام پلتفرم‌ها، کتابخانه‌ها و کد فنی حفظ شده‌اند. تاریخ بحث‌ها، منشأ و عدم قطعیت نویسنده ثبت شده و هیچ ادعایی به راه‌حل تضمین‌شده تبدیل نشده است. مستند تازه با نسخهٔ قدیمی ایشو یکسان فرض نمی‌شود.

کنترل‌های محلی شامل هش متن، حفظ دقیق ۴۷۲ متن قبلی، قابل بازسازی بودن متن‌های جدید از قطعه‌های ثبت‌شده، اعتبار شناسه‌های رابطه و حفظ بایت‌های فایل‌های ارزیابی است. ۱۵ ورودی توسعه و ۱۵ ورودی تست و rubricهای آن‌ها تغییر نکرده‌اند. این کنترل‌ها، اجرای مثال‌ها یا سنجش کیفیت پاسخ RAG نیستند.

## نحوه استفاده و حدود بررسی

برای چانکینگ فقط corpus.jsonl بستهٔ ورودی یا پنج فایل صریح retrieval_corpus بستهٔ کامل انتخاب شود. فیلد text برای تقسیم و امبدینگ است و metadata برای منبع، تاریخ، نسخه و ارتباط نگه داشته می‌شود. نوع linked_reference جدید است و بارگذار باید آن را بپذیرد. فهرست تصمیم‌ها و سایر گزارش‌ها وارد امبدینگ نشوند.

بررسی، یک مرحلهٔ مستقیم از ارجاع‌های متن v04 است؛ لینک‌های داخل کد نمونه و لینک‌های تازهٔ داخل صفحه‌های افزوده به صورت بازگشتی دنبال نشده‌اند. دموها، خدمات خصوصی، تصویر و ویدیو اجرا یا تفسیر نشده‌اند. برای پنج آدرس بلاگ دریافت مستقیم با ۴۰۳ ناموفق بود؛ محتوای آن‌ها افزوده نشده است. چند آدرس قدیمی ناموجود، با عنوان صریح «منبع جایگزین موضوع مشابه» به مستند معتبر مرتبط شدند، بدون ادعای تغییر مسیر تأییدشده.

در پیاده‌سازی بازیابی باید از ارتباط ثبت‌شده برای انتخاب منابع مرتبط استفاده شود؛ ثبت metadata به‌تنهایی باعث بازیابی خودکار مقصد نمی‌شود. چانکینگ، امبدینگ و ارزیابی عملکرد هنوز انجام نشده‌اند و در این مرحله تماس پولی API پروژه انجام نشده است. انتخاب tokenizer و کنترل بودجهٔ ۵ دلاری پیش از امبدینگ همچنان لازم است.
